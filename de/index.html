    Backup file · Sicherungskopie

    Download everything the app remembers as one file, and restore it on any device. Newer progress always wins, so restoring never replaces recent work with older data.

    Sync with GitHub · Synchronisieren

    Keep progress in a private Gist on your GitHub account so your phone and computer stay in step.

    1. On github.com open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Under Account permissions, set Gists to Read and write.
    3. Paste the token here, once on each device.

    Synced with a private Gist on your GitHub account. The token is stored only in this browser.
