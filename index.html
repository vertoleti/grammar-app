Backup file · Резервная копия

Download everything the app remembers (answers, mistakes, flashcard reviews, settings) as one file. Open it on another device to restore it there. Newer progress always wins, so restoring never replaces recent work with older data.

Sync with GitHub · Синхронизация

Keep progress in a private Gist on your GitHub account, so your phone and computer stay in step. It syncs a few seconds after each answer and whenever you open the app.

  1. On github.com open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under Account permissions, set Gists to Read and write. Nothing else is needed.
  3. Paste the token here, once on each device.
