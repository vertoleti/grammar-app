The counting rule

Number ends inNounExample
1 (not 11)nominative singular21 год, один рубль
2, 3, 4 (not 12–14)genitive singular22 года, три рубля
5–9, 0, and 11–14genitive plural25 лет, двенадцать рублей

Only the last word of the number counts: сто двадцать один рубль, сто двенадцать рублей.
